> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver ORBIT EQ v3.0 (`versionCode = 3`, `versionName = "3.0.0"`): refined Soundcore Life Q30 & `NOVA` musical voicing, 5-band MBC De-Esser (`3.5–9.5 kHz` isolation preserving `9.5–20 kHz` air), mode-aware psychoacoustic adaptive references, ISO-226 perceptual loudness, 31-band Analog Tone Tilt, Loudness-Matched A/B Bypass, RBJ biquad EqualizerAPO Parametric EQ parsing, a searchable 36-model offline AutoEQ catalog (with 4 dedicated Q30 modes), and 31-band live frequency response visualization.

## Review Focus

1. **RBJ biquad parametric accuracy & malformed parametric files** — Peaking (`PK`), Low-Shelf (`LS`/`LSC`/`LSQ`), and High-Shelf (`HS`/`HSC`/`HSQ`) magnitude evaluation must match Audio EQ Cookbook analytical targets within `±0.05 dB` at `fc`/DC/Nyquist across 31 ISO bands; malformed `Filter:` lines, `Q <= 0`, out-of-range `Fc`, `NaN`/`Infinity`, or all-`OFF` files must return `AutoEqParseResult.Error` without throwing (pinned in Task 1).
2. **Post-deduplication GraphicEQ point count & catalog search/filter integrity** — Duplicate-frequency inputs collapsing below 3 distinct points (e.g. `"100 -2; 100 0; 100 2"`) must return `Error`; all 36 catalog models must have unique IDs/names, valid categories, finite `[-12, +12] dB` gains, and accurate case-insensitive filtering (pinned in Task 1).
3. **Loudness-Matched A/B Bypass invariants & closed-loop stability** — Matched bypass gain must stay strictly in `[-9.0f, 0.0f] dB`, return `0f` when `isAutoBypassed = true` or `loudnessMatchedBypass = false`, and 200-frame closed-loop stability must remain convergent under the refined `Q30` + `NOVA` + mode-aware references + `DeEsserMode.STRONG` (pinned in Task 2).
4. **5-band MBC De-Esser Band-3 isolation & `31/5 -> 10/4 -> LEGACY_EQ` leak-free fallback** — Enabling `DeEsserMode` with `MbcMode.OFF` must keep Bands 0, 1, 2, 4 transparent (`ratio = 1.0f`) while compressing only Band 3 (`3.5–9.5 kHz`); rejecting `(31, 5)` must retry `(10, 4)` then `LEGACY_EQ` then session `0` with zero leaked handles; manual loudness-matched bypass must ramp EQ to `0 dB` and hold flat matched `inputGainDb` with MBC off, while raw/auto bypass disables the native effect (pinned in Task 3).
5. **v1/v2 -> v3 backup/DataStore migration, UTF-8 BOM & deterministic catalog deduplication** — Importing v1/v2 JSON backups (including UTF-8 BOM-prefixed JSON) must populate v3 defaults cleanly without corrupting state; importing the same catalog entry across devices/backups must share deterministic `catalogId` without duplicating profiles (pinned in Task 4).
