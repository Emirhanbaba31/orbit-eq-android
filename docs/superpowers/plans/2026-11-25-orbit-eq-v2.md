# ORBIT EQ v2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver ORBIT EQ v2.0 (`versionCode = 2`, `versionName = "2.0.0"`): a studio-grade 31-band AutoEQ & closed-loop de-embedded adaptive DSP engine, battery-smart audio service, Quick Settings Tile, Deep Space HUD home widget, album artwork & Next-Mode notification control, JSON backup/restore, Diagnostics export, and expanded unit + Compose UI tests.

**Architecture:** Extends the existing single-activity Jetpack Compose MVVM + singleton `OrbitEngineRepository` + two-tier `OrbitAudioService` architecture with pure-Kotlin testable modules (`AutoEqParser`, `AutoEqCatalog`, `DspLoopCadencePlanner`, `AudioRouteResolver`, `OrbitBackupCodec`, `DiagnosticsFormatter`). Native `DynamicsProcessing` upgrades `PreEQ` to 31 ISO 1/3-octave bands (`20 Hz–20 kHz`) with automatic 10-band and `LEGACY_EQ` fallbacks, click-free gain ramping, per-channel L/R balance attenuation, 3-tier MBC, and dirty-checked JNI writes.

**Tech Stack:** Kotlin 2.2.20, AGP 8.13.0, Gradle 8.14.3, JDK 21, `compileSdk = 36`, `targetSdk = 35`, `minSdk = 28`, Jetpack Compose Material 3, Jetpack DataStore Preferences, Android `DynamicsProcessing` / `TileService` / `AppWidgetProvider` / SAF, JUnit 4, `org.json`, Compose UI Test (`androidx.compose.ui:ui-test-junit4`).

**Spec:** [docs/superpowers/specs/2026-11-25-orbit-eq-v2-design.md](../specs/2026-11-25-orbit-eq-v2-design.md)

## Global Constraints

- Package ID: `com.orbiteq.app`; `minSdk = 28`, `targetSdk = 35`, `compileSdk = 36`, `versionCode = 2`, `versionName = "2.0.0"`.
- Zero new heavy runtime dependencies (no Jetpack Glance, no Coil/Glide, no cloud/network SDKs); keep native `RemoteViews` and standard `android.graphics.Bitmap` downscaling.
- Backward-compatible DataStore migration: existing v1.0 preferences (`mbc_enabled`, `app_rules_json`, `pinned_tracks_json`, `device_profiles_json`, `custom_presets_json`, `recent_history_json`) must load cleanly without data loss.
- 31 ISO 1/3-octave center frequencies: `[20f, 25f, 31.5f, 40f, 50f, 63f, 80f, 100f, 125f, 160f, 200f, 250f, 315f, 400f, 500f, 630f, 800f, 1000f, 1250f, 1600f, 2000f, 2500f, 3150f, 4000f, 5000f, 6300f, 8000f, 10000f, 12500f, 16000f, 20000f]` Hz.
- Limiter ceiling stays `-0.5 dB`; L/R balance attenuates the opposite channel up to `-12.0 dB` (never positive boost).
- Android 14–16 FGS safety: background triggers (Tile, Widget, BroadcastReceiver, NotificationListener) always attempt `TIER2_PROFILE_ONLY` (`mediaPlayback`) and catch `ForegroundServiceStartNotAllowedException`/`SecurityException` with safe Activity fallback when user-initiated.
- UI rules: zero emojis as icons (vector icons only), `>= 48dp` touch targets, `360dp` compact width safety, bilingual `values-tr/strings.xml` + `values/strings.xml`, Deep Space HUD & Lunar Monochrome theme consistency.
- Git hygiene: never commit `*.jks`, `keystore.properties`, `local.properties`, `build/`, `.gradle/`.

## Review Focus

1. **Closed-loop FFT de-embedding stability across OEMs** — running 200 consecutive frames with `GRAVITY` + `Q30_CLEAN_BASE` on a steady spectrum (both post-effect and pre-effect scenarios) must converge smoothly within bounds without oscillation or runaway (pinned in Task 2).
2. **Linear FFT Wiener entropy separation** — balanced/pink and bass-heavy tonal music must score `< 0.55f` (never tripping the `>= 0.72f` noise guard), while flat white/quantization noise must score `>= 0.72f` and gently decay `smoothedDelta` while keeping `AUTO_FFT_LOCKED` (pinned in Task 2).
3. **Malformed `GraphicEQ.txt` and JSON backup inputs** — empty text, zero/negative frequencies, `NaN`/`Infinity`, unordered/duplicate points, or corrupt backup JSON must never crash and must leave repository state intact on failure (pinned in Task 1 & Task 4).
4. **31-band -> 10-band -> Legacy DSP fallback, zero-click bypass ramp, and dirty-write suppression** — rejecting 31-band `DynamicsProcessing` must retry 10-band then `LEGACY_EQ` without leaking handles; bypass must ramp gains to `0 dB` before `setEnabled(false)`; identical frames must trigger zero redundant native writes (pinned in Task 3).
5. **Android 14–16 Tile/Widget FGS restriction & v1->v2 migration** — `startBackgroundSafe()` catching FGS start denial and returning `false` cleanly; migrating legacy `mbc_enabled = false` (absent `mbc_mode`) to `MbcMode.OFF` (pinned in Task 4 & Task 5).
