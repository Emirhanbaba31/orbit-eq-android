# ORBIT EQ Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build ORBIT EQ — a native Android Kotlin + Jetpack Compose real-time hybrid Auto-EQ application with a Black/White/Blue Space HUD UI, Soundcore Life Q30 compatibility, signed installable APK, and private GitHub repository + Release delivery.

**Architecture:** Single-activity Jetpack Compose MVVM app (`MainActivity` + `OrbitViewModel`) connected via a singleton reactive `OrbitEngineRepository` (`StateFlow<OrbitUiState>`) to a two-tier Android Foreground Service (`OrbitAudioService`). Pure Kotlin DSP modules (`FftAnalyzer`, `AdaptiveEqEngine`, `PleasureProfiles`, `AppRuleResolver`) run unit-tested off-device and execute on a background coroutine inside the service, driving `DynamicsProcessing` (10-band PreEQ, 4-band MBC, 10-band PostEQ, `-0.5 dB` True-Peak Limiter, dynamic input gain) with automatic `Equalizer` fallback and `OrbitNotificationListenerService` media tracking.

**Tech Stack:** Kotlin 2.2.20, Android Gradle Plugin 8.13.0, Gradle 8.14.3, JDK 21, `compileSdk = 36`, `targetSdk = 35`, `minSdk = 28`, Jetpack Compose Material 3, Jetpack DataStore Preferences, JUnit 4, GitHub CLI (`gh`), GitHub Actions.

**Spec:** [docs/superpowers/specs/2026-11-25-orbit-eq-design.md](../specs/2026-11-25-orbit-eq-design.md)

## Global Constraints

- Package ID: `com.orbiteq.app`; App name: `ORBIT EQ`; `minSdk = 28`, `targetSdk = 35`, `compileSdk = 36`.
- ISO 10-band center frequencies: `[31, 62, 125, 250, 500, 1000, 2000, 4000, 8000, 16000]` Hz.
- 5 Pleasure Modes verbatim: `NOVA`, `GRAVITY`, `HORIZON`, `ECLIPSE`, `COMMS`.
- Soundcore Life Q30 profiles verbatim:
  - `Q30_CLEAN_BASE`: `[-1.5f, -3.5f, -4.5f, -3.0f, -0.5f, +0.5f, +2.0f, +2.5f, -1.5f, +0.5f]` dB, `extraHeadroomDb = 0.0f`
  - `Q30_SAFE_STACK`: `[-1.0f, -2.0f, -2.5f, -1.5f, 0.0f, +0.5f, +1.0f, +1.0f, -1.0f, 0.0f]` dB, `extraHeadroomDb = 2.0f`
  - `FLAT_GENERIC`: 10 zeros, `extraHeadroomDb = 0.0f`
  - `PHONE_SPEAKER_SAFE`: `[-6.0f, -4.0f, -1.5f, 0.0f, +0.5f, +1.0f, +1.0f, +0.5f, 0.0f, -1.0f]` dB, `extraHeadroomDb = 0.0f`
- Dynamic Preamp Headroom formula: `inputGainDb = -max(0f, peakPositiveTotalGainDb - 1.5f) - extraHeadroomDb`.
- Limiter ceiling fixed at `-0.5 dB` (`ratio = 10.0f`, `attackTime = 1.0f`, `releaseTime = 60.0f`); HUD displays exact Dynamic Preamp attenuation (`PREAMP -X.X dB`) + static `LIM -0.5 dB` badge (never a fabricated GR estimate).
- Two-tier Foreground Service on API 34+: `mediaPlayback|microphone` when started/promoted in foreground with `RECORD_AUDIO`; `mediaPlayback`-only (`PROFILE_FALLBACK`) when triggered from background.
- UI rules (`ui-ux-pro-max`): Deep Space HUD default (`#03050A`, `#0B0F1A`, `#F8FAFC`, `#3B82F6`, `#38BDF8`) + Lunar Monochrome toggle (`#000000`, `#FFFFFF`, `#2563EB`); bundled `Space Grotesk`, `DM Sans`, `Space Mono` fonts; tabular numerals (`tnum`) on live readouts; **zero emojis as icons** (vector icons only); `>= 48dp` touch targets; edge-to-edge `WindowInsets`; bilingual `values-tr/strings.xml` + `values/strings.xml`.
- Git hygiene: `.superpowers/`, `build/`, `.gradle/`, `local.properties`, `*.jks`, `*.keystore` MUST be in `.gitignore` and never committed.

## Review Focus

1. **Malformed, empty, or all-zero `Visualizer` FFT byte buffers** (e.g., `ByteArray(0)`, `ByteArray(2)`, or all-zero DRM stream frames) must never throw `ArrayIndexOutOfBoundsException`, produce `NaN`/`Infinity`, or corrupt band smoothing — pinned in Task 2 tests.
2. **Extreme gain stacking** (e.g., `GRAVITY` + `+8.0 dB` Sub Impact + `+8.0 dB` manual trim + `Dynamic Loudness` at low volume + `Q30_SAFE_STACK`) must clamp band gains safely and drive `inputGainDb` sufficiently negative so combined gain never digitally clips — pinned in Task 2 tests.
3. **Pinned track eviction & rule collisions** (adding > 50 unique songs to listening history while a track is pinned, or Q30 connecting during a pinned YouTube song with a manual override active) must never evict pinned songs or alter Q30 headphone compensation — pinned in Task 3 tests.
4. **Android 14+ background `SecurityException` on `microphone` FGS** (background Bluetooth Q30 connect / audio session trigger when app is not foreground or `RECORD_AUDIO` is denied) must select Tier-2 `mediaPlayback`-only FGS without throwing — pinned in Task 4 state-machine tests.
5. **Rapid Bluetooth reconnect / `DynamicsProcessing` OEM creation failure** must release stale handles without leaking native audio sessions and fall back to `LEGACY_EQ` (`Equalizer`) cleanly — pinned in Task 4 controller tests.
